## Filter dropdown categories are not in alphabetical order

### Jira: https://aggreycnhiwatiwa.atlassian.net/browse/ASK-25

## Description
The categories in the filter are not displayed in alphabetical order. The sort options are also in alphabetical order.

## Environment

- **Browser:** [Chrome]
- **Device:** [Desktop]
- **OS:** [macOS]

## Preconditions

- Authorized user is logged in

## Steps to Reproduce

1. Login as an authorized user
2. On the store page open the categories dropdown

## Expected Result
The order of categories should be alphabetically arranged as so: Accessories, Apparel, Books, and Gear

## Actual Result
The order of categories is Apparel, Accessories, Gear, and Books

## Impact
Minimal user impact. This may become more significant if more categories are added.

## Reproducibility

Always

## Cart Button missing highlight when on the cart page

### Jira: https://aggreycnhiwatiwa.atlassian.net/browse/ASK-8

## Description
The cart button does not have a UI highlight when the cart has been selected (unlike the store page, for example).

## Environment

- **Browser:** [Chrome]
- **Device:** [Desktop]
- **OS:** [macOS]

## Preconditions

- Authorized user is logged in

## Steps to Reproduce

1. Login as an authorized user
2. Click the cart button in the NavBar
   
## Expected Result
The cart button should be highlighted yellow when on the cart page

## Actual Result
The cart button is not highlighted when on the cart page

## Impact
As the store page is highlighted when on that page, the lack of highlight here may cause some user pain points. For example, 'am I in the right cart?'

## Reproducibility

Always

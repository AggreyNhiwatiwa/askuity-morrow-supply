## [StorePage][ItemPage] The Bolt T-Shirt cannot be added to the Cart

### Jira: https://aggreycnhiwatiwa.atlassian.net/browse/ASK-4

## Description

On both the Store Page and the Item Page, the 'Bolt T-Shirt' cannot be added to the cart. The add to cart button does display the same visual consistencies as the other product button, however, it cannot be added to the cart.

## Environment

- **Browser:** [Chrome]
- **Device:** [Desktop]
- **OS:** [macOS]

## Preconditions

- Authorized user is logged in

## Steps to Reproduce

1. Login as an authorized user
2. On the store page, click the 'Add to Cart' button for the Bolt T-Shirt
3. Click on the Bolt T-Shirt name or icon
4. On the details page for the Bolt T-Shirt, click the add to cart button

## Expected Result

Clicking the add to cart button on either page should result in the item being added to the cart, with the cart badge number updating to reflect the number of added Bolt T-Shirts.

The cart page itself should also display the correct number of added Bolt T-Shirts.

## Actual Result

No Bolt T-Shirts are added to the cart.

## Impact

This item cannot be purchased, resulting in pain points for customers wanting to purchase the item, as well as lost revenue.

## Reproducibility

Always
